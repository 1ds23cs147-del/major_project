Connect IP Webcam

  1. Install IP Webcam from the Play Store on the phone.
  2. Join the phone and this computer to the same wifi.
  3. Open the app, scroll down, tap Start server.
  4. Read the address at the bottom of the phone screen, something like 192.168.1.7:8080.
  5. Paste it into the add form. The stream path is worked out for you — leave it off unless you already know it.
On iPhone, apps that expose an MJPEG stream work the same way. If you paste a URL that already names a path, like http://…/video, or an RTSP URL, it is used exactly as given.
Thermal cameras. Add the thermal feed as its own camera, set its channel to Thermal, then edit the visible camera and pick it as the paired channel. Live detection will then fuse both, exactly like the classifier does with uploads.
